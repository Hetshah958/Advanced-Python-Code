# Experiment 15 - Python Garbage Collection

Creates unreachable reference cycles, reports traced memory before and after creating them, manually invokes `gc.collect()`, and displays GC thresholds/counts. `tracemalloc` is used to measure Python-traced allocations; these values are not the same as total process RAM. Run `python "garbage collection.py"`.
