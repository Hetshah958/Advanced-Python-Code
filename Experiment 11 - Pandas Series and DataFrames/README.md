# Experiment 11 - Pandas Series and DataFrames

Creates a Pandas Series with ten random values and demonstrates DataFrame creation, selection, indexing, missing-value handling, duplicate removal, and aggregation. Install dependencies with `pip install -r requirements.txt`, then run `python "pandas series and dataframes.py"`.
