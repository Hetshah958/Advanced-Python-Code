# Experiment 12 - Exploratory Data Analysis

Performs EDA: previews and describes the dataset, computes descriptive statistics, saves histograms/boxplots/scatter plot/correlation heatmap, handles missing values, detects z-score outliers, caps numeric outliers, and exports a cleaned CSV. Place your actual `customer_churn.csv` beside the script to analyze it. If absent, an illustrative sample dataset is used (not the university dataset). Run `pip install -r requirements.txt` then `python "exploratory data analysis.py"`.
