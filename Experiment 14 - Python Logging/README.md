# Experiment 14 - Python Logging

Configures a named logger with console and file handlers, a timestamped formatter, and DEBUG level. Demonstrates DEBUG, INFO, WARNING, ERROR, and CRITICAL. Running the script creates/appends to `app.log`. Run `python "logging demonstration.py"`.
